# duabelasjuni

File ini siap dipakai untuk GitHub Pages.

Struktur:
- index.html
- images/foto1.jpg
- images/foto2.jpg
- images/foto3.jpg
- music/lagu.mp3

Cara pakai:
1. Upload semua isi ZIP ini ke repository GitHub.
2. Ganti foto di folder images dengan foto pribadi. Nama file sebaiknya tetap: foto1.jpg, foto2.jpg, foto3.jpg.
3. Ganti lagu di folder music dengan file mp3. Nama file sebaiknya tetap: lagu.mp3.
4. Aktifkan GitHub Pages dari Settings > Pages > Branch main > root.
5. Buka link GitHub Pages yang muncul.
